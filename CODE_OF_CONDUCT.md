# Code of Conduct

SolvFC follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the project. Harassment, insults, and personal attacks are not tolerated in issues, pull requests, or any other project space.

## Reporting

If someone's behavior makes you uncomfortable, contact the maintainer privately at the email on [@Papunidze](https://github.com/Papunidze)'s GitHub profile. Reports are kept confidential.

Maintainers may edit or remove comments, close threads, or block users who don't follow this code.
