# Getting help

- **Bug or broken button?** Open a [Bug report](https://github.com/Papunidze/SolvFc/issues/new?template=bug_report.yml).
- **Solver chose a bad squad?** Open a [Solver result](https://github.com/Papunidze/SolvFc/issues/new?template=solver_result.yml).
- **Feature idea?** Open a [Feature request](https://github.com/Papunidze/SolvFc/issues/new?template=feature_request.yml).

Before opening an issue, check that you're on the latest version and search [existing issues](https://github.com/Papunidze/SolvFc/issues?q=is%3Aissue).

EA Web App updates sometimes break things for a short time. If the extension suddenly stops working after an EA update, look for an open issue labeled `ea-update` first.
